Import from CSV

Upload a CSV with one row per completion. The template uses UTF-8; ESR “Compliance and Competency” exports are often Windows-1252 — the server detects encoding. ESR columns such as Competency Name, Title, Date Last Awarded, Date Start, Expiry Date, Last Updated By (assignment|Name), and VPD are mapped automatically. Rows without a person line are skipped. Check the file first, then issue all valid rows. Bulk import (more than one row) does not attach PDFs to each item so the request can finish in time — verification links and QR still work; use single-row add if you need a PDF saved next to a record.
