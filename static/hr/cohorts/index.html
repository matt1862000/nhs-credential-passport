Add doctors

Create doctor accounts using each person’s personal email as their login, organise them into groups, and send the same message to everyone (each replies in their own thread).

HR never sees passwords here. Send login details to each person’s personal email outside DocPass. Demo accounts use a standard initial password; doctors must change it on first sign-in.
