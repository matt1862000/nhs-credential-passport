Cohorts

Create clinician accounts using each person’s personal email as their login, group them into cohorts, and send the same message to everyone (each replies in their own thread).

HR never sees passwords here. Send login details to each person’s personal email outside DocPass. Demo accounts use a standard initial password; clinicians must change it on first sign-in.

This page is only for HR accounts.
